Human Typer 2.0 — от черновика к готовому тексту.

- Сценарии в буфере обмена: `[[пауза:2]]`, `[[слова:2]]`, `[[предложения:1]]`, `[[стереть:12]]`, `[[заменить:старое=>новое]]`, `[[скорость:180]]`.
- Возврат к предыдущему фрагменту, постепенное удаление и переписывание, продолжение с конца текста.
- Предпросмотр результата и порядка действий, встроенный пример, меню команд и загрузка файлов UTF-8.
- Без лимита длины текста; проверен миллион символов, операции разворачиваются по мере выполнения.
- F8 приостанавливает правку и явное ожидание; F9 отменяет остаток сценария.
- Ошибки сценария обнаруживаются до первого нажатия. Команды удаляют только уже написанный сценарием текст.

Скачайте архив для Windows x64, macOS Intel (x64) или Apple Silicon (arm64). Python не нужен. На macOS разрешите «Универсальный доступ» и при необходимости «Мониторинг ввода»; после обновления система может попросить выдать разрешение повторно. Сборки не подписаны платным сертификатом и не нотарифицированы Apple. Для локальной сборки, созданной на вашем Mac, повторная загрузка не нужна.

Справка с примерами: [docs/SCENARIOS.md](https://github.com/daryynchik/human-typer/blob/main/docs/SCENARIOS.md).
